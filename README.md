# Java Practice Lab

A hands-on repository for revising and strengthening my Java fundamentals, Object-Oriented Programming, Collections, Exception Handling, Design Patterns, Streams, and other core Java concepts.

The goal of this project is not just to review Java syntax, but to **practice writing, explaining, and structuring Java code through progressively more complex exercises**.

---

## 🎯 Goals

* Refresh Java fundamentals and syntax
* Strengthen Object-Oriented Programming concepts
* Understand Java Collections and when to use each one
* Practice exception handling and custom exceptions
* Review Java's access modifiers and encapsulation
* Understand `String` immutability and mutable string alternatives
* Learn and implement common Design Patterns
* Practice the Java Stream API
* Write clean, readable, and maintainable Java code
* Build practical examples that can be discussed in technical interviews

## 🧠 Interview Questions

Each topic will also include questions that I should be able to answer without relying on notes.

Examples:

### OOP

* What is encapsulation?
* What is inheritance?
* What is polymorphism?
* What is abstraction?
* What is the difference between an abstract class and an interface?

### Collections

* What is the difference between `List`, `Set`, and `Map`?
* When would you use `ArrayList` instead of `LinkedList`?
* What is the difference between `HashSet` and `TreeSet`?
* How does a `HashMap` work at a high level?

### Strings

* Why is `String` immutable in Java?
* What is the difference between `String`, `StringBuilder`, and `StringBuffer`?
* When would you use `StringBuilder`?

### Exceptions

* What is the difference between checked and unchecked exceptions?
* What is the difference between `throw` and `throws`?
* When should you create a custom exception?

### Design Patterns

* What problem does the Singleton pattern solve?
* What is the Factory pattern?
* What problem does the Facade pattern solve?
* What are the disadvantages of Singleton?

### Streams

* What is a Stream?
* What is the difference between `map()` and `filter()`?
* What is `reduce()` used for?
* What is the difference between a Stream and a Collection?

## 🛠️ Approach

The repository follows a practical learning approach:

```text
Learn
  ↓
Understand
  ↓
Implement
  ↓
Solve an exercise
  ↓
Refactor
  ↓
Explain
```

The objective is to avoid simply memorizing Java concepts.

For each topic, I want to be able to answer three questions:

> **What is it?**

> **Why does it exist?**

> **When would I use it?**
